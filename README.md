# Lista de Tarefas

App de lista de tarefas em React + Vite, feito como exercício de estudo.

- Adicionar, concluir e remover tarefas
- As tarefas ficam salvas no navegador (`localStorage`), com tratamento de erro se os dados salvos estiverem corrompidos
- Sem back-end: tudo roda no navegador

## Rodar

```bash
npm install
npm run dev     # servidor de desenvolvimento
npm run build   # gera a pasta dist/
```
